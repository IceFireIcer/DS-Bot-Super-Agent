协作状态模型原型

这个原型要回答一个具体问题：当两项工作并行、用户跨信道跟进、工作等待人或设备、随后停止或发生 Host 接管时，是否能清楚看出谁在做什么、下一步由谁决定、结果会发到哪里？点击按钮走查状态变化。所有数据只在本页面内存中存在。

    你需要判断的边界

    1. 跟进是否回到原 Worker，同时保持原授权和工作归属？
    2. 人工 stop 后，设备重新上线或 Watchdog 检查是否会偷偷恢复？
    3. Host 接管后，旧回调是否只留下审计事实，不能改写新 Assignment？
    4. 一个工作结果未知时，无关工作是否仍能继续？
