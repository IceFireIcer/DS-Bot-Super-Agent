## Question

采用什么最小远程能力组合，验证两个 Worker 各自的文件、搜索、shell、输出和取消处于同一执行环境，尤其在 Host 与设备操作系统不同时仍具有一致路径与可执行文件语义？

官方搜索工具使用 Host 打包的 ripgrep 路径和 Host 的路径处理；jobs-local 的 live 作业不会因恢复 Session 自动续跑。实验需要在公开 provider/工具扩展位置确定 executable 映射、工作目录、文件目标、结果路径、作业 ID 与重连查询的具体做法，避免通过修改 DSH 安装文件绕过。

使用两个隔离环境的同名文件验证无串线；在启动、执行和结果传输窗口断连，记录实际作业状态、取消确认和未知结果。可以先用分进程模拟缩小问题，但必须标识同平台或模拟环境的证据边界，不宣称真实异构第二设备已验收。

产出可复跑实验、采用的能力组合、支持范围、剩余缺口，供执行所有权决定使用；不交付完整 daemon。依据：[确认 DSH 远程执行能力与作用域合约](https://github.com/IceFireIcer/DS-SuperAgent/issues/4)。
