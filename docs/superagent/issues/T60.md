## What to build

新增独立前端包 `ds-superagent-ui`，从 `ds-bot` 复制聊天外壳、消息单元格、输入框、问题卡、主题和布局，使用自己的 build id 和 `/api/superagent` 路由。新 profile 不再挂载 `ds-bot` Host，只挂公开 Super-agent Engine 和新的 UI host。

本票只交付 v1 单会话界面：发起、确认、结果、Attention 回答、stop、resume、重连补读和证据展开。群聊、浏览器、附件、steer、记忆、日程、用量、密钥和团队管理隐藏或明确拒绝。

## Acceptance criteria

- [ ] `ds-superagent-ui` 作为独立 DSH 客户端 bundle 加载，使用自己的 `dsh.client` 清单和生成的 `client.js`；不手工编辑生成文件。
- [ ] 新 UI 的 `api` 层只调用 `/api/superagent`，路由由新 UI host 通过公开 `connection.fetch.register` 提供。
- [ ] 一条 mock 模型消息可以完成提交、确认、结果和证据展开；刷新页面后历史和结果仍可读。
- [ ] Attention 问题可以在原对话就地回答；stop 生效并可显式 resume；重连后按游标补读，不重复渲染已读结果。
- [ ] v1 未实现的入口隐藏或返回明确拒绝；不出现可点击但失败的群聊、浏览器、附件、steer、记忆、日程、用量或团队管理按钮。
- [ ] `ds-bot/src/client/` 和 `ds-bot/client.js` 保持零 diff；新包有独立的生成一致性检查和 UI host 契约测试。
- [ ] `app/ui/` 不改动；新增 `ds-superagent-ui` 前端属于 2026-11-12 用户明确要求的界面分叉，提交前 `DSBOT_UI_CHANGE_APPROVED=1` 运行 UI 边界检查。
- [ ] 测试使用隔离数据、mock 模型和空闲端口；本轮启动的 Host、Session、Effects 和进程全部停止。
