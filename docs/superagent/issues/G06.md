- [ ] 用户可检查需要人的工作、追查依据并按版本安全调整已授权配置。 提供一条完整功能场景与核查证据。

- [ ] 领域/契约、mock 集成和适用的真实模型/信道/设备/Windows 证据分别列明，未验收项不得标完成。
