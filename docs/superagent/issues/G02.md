# [Feature G02] 持续协作与人工控制

<!-- dsbot-plan:v2.1:G02 -->

## Parent

[Super-agent 架构重建规格 v2.1](https://github.com/IceFireIcer/DS-SuperAgent/issues/1)

## What to build

用户跟进、交回、提问、停止和恢复同一工作，策略变化不丢输入或扩权。

## Child tickets

- T06 跟进原工作并恢复自然结束的任务
- T07 处理多订阅、只读上下文与越界交回
- T08 就地提出人工问题并由授权回答继续
- T09 持久停止本地工作并显式恢复
- T10 调整策略和暂停处理而不丢失输入

子票通过 GitHub 原生 sub-issues 绑定；上列编号对应稳定计划 ID。父票只聚合功能范围与验收，不作为一张超大实施任务。

## External prerequisites

T03、T05。这些前置只约束使用它们的子票；不得转换为整功能互相等待。跨功能逐票 blocked-by 为执行依据。

## Acceptance criteria

- [ ] 用户跟进、交回、提问、停止和恢复同一工作，策略变化不丢输入或扩权。 提供一条完整功能场景与核查证据。
- [ ] 所有子票满足各自验收，并补齐本功能使用的跨功能具体前置；不能以父票归组替代依赖。
- [ ] 领域/契约、mock 集成和适用的真实模型/信道/设备/Windows 证据分别列明，未验收项不得标完成。

## Execution

从本功能尚未完成且原生 blockers 已满足的子票开始；每票保持独立验收。功能整体验收在子票完成后进行。父票 enhancement 表示聚合范围，不代表可以忽略子票前置或已通过产品验收。
