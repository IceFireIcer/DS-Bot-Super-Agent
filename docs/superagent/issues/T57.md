## Parent

[T55 验收四目标的完整产品协作场景](https://github.com/IceFireIcer/DS-SuperAgent/issues/83)

## What to build

为真实模型、隔离 GitHub 仓库和隔离飞书租户/群建立可重复的验收环境与配置入口。该票可以增加环境检查、配置读取、验收脚本和证据输出，但不创建替代 UI，也不把 mock、协议夹具或本地 delivery 冒充真实模型/信道结果。

## Acceptance criteria

- [ ] 提供不打印凭据的环境检查命令，分别验证真实模型 route、GitHub 仓库/令牌权限、飞书 app/tenant/chat 权限；缺失配置明确失败或标未验收，不伪造通过。
- [ ] 用一个受预算限制的真实模型样本覆盖跨信道意图、范围遵守、主动规则误触发、Supervisor 语义干预和受信配置指令；记录 provider/model、调用/时间/token 预算、结果与失败原因。
- [ ] 在隔离 GitHub 仓库完成 Issue/PR/review/check 输入，并通过真实 GitHub delivery channel 发出结果评论、读回平台回执；不得使用 `localDeliveryChannel` 或仅检查本地 Outbox。
- [ ] 在隔离飞书群完成讨论接收、就地问题/授权回答和结果交付，记录 tenant/chat/sender 身份与原生回执（脱敏）；真实租户或权限不可用时本票保持未完成。
- [ ] 提供可重跑命令和机器可读证据，凭据只从环境/密钥注入；mock/协议夹具证据与真实模型/信道证据分开报告。
- [ ] 清理本轮创建的分支、PR、评论、群消息、临时 Host 和进程；不读取或写入用户自有 DSH 数据，不在仓库、日志或截图中暴露密钥。

## Delivery requirements

- 本票只交付真实环境接入、配置检查、验收脚本和证据；production factory 装配由 T56 负责，托管 Host 与第二设备组合由 T58 负责。
- 真实凭据只从环境变量或受保护的本地配置读取；不得写入仓库、测试输出、日志、GIF 或问题正文。测试使用隔离 GitHub 仓库、隔离飞书租户/群和临时数据。
- GitHub 外发必须使用真实平台 API 并读回回执；飞书必须使用真实租户/群。协议夹具、mock 模型和本地 delivery 只能作为实现前测试，不能作为本票验收证据。
- 真实模型样本要有明确预算和停止条件；发现超限或语义错误时记录具体失败，不用扩大重试掩盖。
- 所有本轮创建的外部资源要列出并清理或明确保留原因；不触碰用户个人 DSH 数据、个人 GitHub 账号数据或生产飞书群。
