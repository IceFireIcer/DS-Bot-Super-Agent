## Parent

[Super-agent 架构重建规格 v2.1](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/1)

## What to build

独立任务并行，长命令与子代理不阻塞人工交互，验收时正确释放执行资源。

## Child tickets

- T11 并行两项工作并优先处理人工跟进
- T12 长命令异步执行并把完成事件送回原 Worker
- T13 子代理与 Agent Team 继承工作授权和环境
- T14 交付验收时释放执行槽并管理预览服务

子票通过 GitHub 原生 sub-issues 绑定；上列编号对应稳定计划 ID。父票只聚合功能范围与验收，不作为一张超大实施任务。

## External prerequisites

T03、T06、T09。这些前置只约束使用它们的子票；不得转换为整功能互相等待。跨功能逐票 blocked-by 为执行依据。

## Acceptance criteria

- [ ] 独立任务并行，长命令与子代理不阻塞人工交互，验收时正确释放执行资源。 提供一条完整功能场景与核查证据。
- [ ] 所有子票满足各自验收，并补齐本功能使用的跨功能具体前置；不能以父票归组替代依赖。
- [ ] 领域/契约、mock 集成和适用的真实模型/信道/设备/Windows 证据分别列明，未验收项不得标完成。

## Execution

从本功能尚未完成且原生 blockers 已满足的子票开始；每票保持独立验收。功能整体验收在子票完成后进行。父票 enhancement 表示聚合范围，不代表可以忽略子票前置或已通过产品验收。
