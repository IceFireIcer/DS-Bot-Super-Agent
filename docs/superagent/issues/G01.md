## Parent

[Super-agent 架构重建规格 v2.1](https://github.com/IceFireIcer/DS-Bot-SuperAgent/issues/1)

## What to build

用户提交授权请求，持久接单、正确研判并在独立本地目录完成任务。

## Child tickets

- T01 建立隔离实例的持久接单与查询闭环
- T02 通过原生 Router 与 Worker 返回首个结果
- T03 在绑定的本地工作目录完成实际工具任务
- T04 正确接收来源版本、删除与身份冲突
- T05 对新请求进行有依据的批量研判

子票通过 GitHub 原生 sub-issues 绑定；上列编号对应稳定计划 ID。父票只聚合功能范围与验收，不作为一张超大实施任务。

## External prerequisites

无。这些前置只约束使用它们的子票；不得转换为整功能互相等待。跨功能逐票 blocked-by 为执行依据。

## Acceptance criteria

- [ ] 用户提交授权请求，持久接单、正确研判并在独立本地目录完成任务。 提供一条完整功能场景与核查证据。
- [ ] 所有子票满足各自验收，并补齐本功能使用的跨功能具体前置；不能以父票归组替代依赖。
- [ ] 领域/契约、mock 集成和适用的真实模型/信道/设备/Windows 证据分别列明，未验收项不得标完成。

## Execution

从本功能尚未完成且原生 blockers 已满足的子票开始；每票保持独立验收。功能整体验收在子票完成后进行。父票 enhancement 表示聚合范围，不代表可以忽略子票前置或已通过产品验收。
