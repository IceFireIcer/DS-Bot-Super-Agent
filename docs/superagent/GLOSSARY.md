# Super-agent 领域词汇补充

- **来源实例（Source instance）**：一份具体来源接入范围的持久身份；它与可复用的来源类型不同。
- **逻辑来源对象（Logical source object）**：来源中的一条消息或资源；编辑产生新版本时仍是同一对象。
- **版本事件（Versioned event）**：某个逻辑来源对象的一次已观察创建、编辑或删除事实。
- **当前投影（Current projection）**：根据已核查版本事实形成的对象当前视图；它不代替历史依据。
- **关联证据（Association evidence）**：支持把输入交给某项已有工作的来源引用和核查依据；它本身不授予新的工作权限。

- **运维恢复（Operational recovery）**：在既有授权内恢复故障服务可用性的操作，不改变工作目标或解除人的停止。
- **语义干预（Semantic intervention）**：针对任务无进展或方向偏离而采取的纠偏、暂停等动作；与故障查询及安全重试不同。
- **执行权威链（Execution authority chain）**：从 Instance 协调锁到 Host、Assignment、Session、Environment 和设备 job 的逐层写权与代次核验链；下层回调只有在整条链仍有效时才能改变当前状态。
- **未知结果（Unknown outcome）**：外部操作可能已经发生但当前无法可靠确认其结果的持久事实；它要求有界查证或人工决定，不能被当作失败而盲目重做，也不能被当作成功。
- **人工停止（Human stop）**：用户明确要求停止某项工作的持久约束；它优先于自动恢复和 Host 接管，设备重新上线也不会自动解除。
- **Assignment（执行安排）**：某个 Ticket 的一次具体执行绑定；可以换代，但同一时刻只能有一个有效执行安排。
- **等待人工（Waiting human）**：工作已经提出结构化问题，下一步由具备权限的用户回答推动。
- **等待设备（Waiting device）**：工作等待设备或外部条件回报的正常状态，不自动视为失败。
- **未知结果（Unknown outcome）**：外部操作可能已经发生但结果无法可靠确认的状态；只局部暂停并等待对账或人工决定。
