# T24：从监督视图追查需要人处理的工作

- Issue：[T24 / #52](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/52)。依据：规格 v2.1 D02、D07、D10、D11、D17，A05、A09、A12、A13、A16、A38、A43。
- 固定实施基线：`90ecb33`。

## 交付行为

新增公开 `engine.getSupervision()` 读模型。它从 Ticket、conversation、Attention、stop、setup、Effect、job、subagent、slot 和 report 的公开事实重建，不持有独立状态。条目按风险排序：

1. waiting-human；
2. unknown Effect/job 或 setup 失败；
3. stopping/stopped；
4. ready；
5. running/pending/ended。

每个条目包含 `nextAction`、为什么开始的 trigger/Decision/Mandate、当前 Assignment/generation、report、Attention、stop、消息回执、槽与分项 health。未知 Effect/旧作业只标记对应 Ticket 为 blocked，不把其他 Ticket 或整个实例误报为失效。

本地预览新增 `/supervision` 同源 JSON 与 “Needs you” 面板。面板提供回答、停止、恢复、重试 setup、重试 Assignment；同源 `/requeue`、`/unsubscribe`、`/dismiss-eval` 提供人工重评、撤订阅和 dismiss unavailable 的受控入口。刷新只重读公开事实，不改变状态或重发命令。界面使用现有主题、键盘焦点与英文源文案。
