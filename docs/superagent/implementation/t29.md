# T29：在规则预算内主动准备可审阅结果

- Issue：[T29 / #57](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/57)。
- 固定实施基线：`3e807ea`。

## 已交付

- 版本化 `ProactiveRule`：触发 actor 种类、addressing、文本模式、沟通方式、每窗口预算与启用状态；revision CAS、重放与非法正则/未知键拒绝。
- observe 只记录 `proactive-run`，不调用准备回调、不启动 Worker。
- auto 只处理命中规则且能对应当前已记录来源事件的候选；直接传入未记录或已过期的候选被 `SOURCE_NOT_CURRENT` 拒绝。
- bot/CI 的重复文本在预算窗口内记录 `suppressed`（`REPEATED_ECHO`）且不消耗准备预算；新的 bot/CI 候选仍可由授权规则准备；ambient 记录 `AMBIENT`。规则授权的 `system` 定时 occurrence 可以准备，计时器本身仍不构成授权。
- 准备使用 root 下按 rule/event 隔离的目录与剩余预算；准备回调通过注入契约执行，返回有效摘要记录 `prepared`，无有效结果记录 `silent`，异常/超时记录 `failed`。
- 规则 ID 必须是可用作目录名的小写 slug；隔离目录在解析后必须仍位于配置 root 下。
- 回调声明的产物必须落在本 run 的隔离目录内，且文件存在、字节数与 SHA-256 与声明一致；总字节数受规则 `maxArtifactBytes`（默认 5 MB）约束。任一项不满足记录 `ARTIFACT_UNVERIFIED` 或 `ARTIFACT_BUDGET`，不保存未核验产物。
- 每次 run 记录候选文本、author/addressing、沟通方式、规则 revision、模型摘要（若有）与原因，供 observe 复核误触发。
- 准备不产生 Outbox、发布、发信、PR 或合并权限；暂停全局处理时不评估主动规则。
- 状态在事务中先预留，准备在事务外执行，完成后按同一运行身份结算；同一事件同一规则重放不重复运行；运行历史按时间可查。

## 真实模型小样本（2026-11-09）

- 真实端点与模型：`https://pro.pokexiao.com/v1/chat/completions`，`deepseek-v4.1-flash-1017`；密钥只经环境变量传入，不写入任何文件或输出。
- 4 次 prepare 调用 / 4 次真实 HTTP 请求（无重试），确定性规则与预算测试单独保留：
  - 具体 bug 报告 → `prepared`，产物 `reproduction.md` 通过隔离目录、字节数与 SHA-256 校验；
  - 普通日程通知 → 模型判为无价值 → `silent`；
  - 同一 bug 的 bot 回声 → `suppressed`（`REPEATED_ECHO`），未调用模型；
  - 第二个具体 bug → `prepared`；
  - 第三个具体 bug → `budget-exhausted`（3/3）；
  - observe 规则对同一批候选只记录 `observed`，不调用模型。
- 组合验收：真实 `ScheduleSource` 产生一个 occurrence，经授权 `system` 规则触发真实模型准备，状态 `prepared` 并记录 167 字节的核验产物。
- 整个过程 `effects` 为 0：没有结果投递、发布、发信或合并动作。
- 复现命令：`POKEXIAO_API_KEY=<key> node dev/proactive-model-acceptance.mjs`；脚本不写、不打印密钥，输出只含 endpoint host。

## 边界

- 只有一个真实 provider/model 与 4 个样本；这证明意图/范围/误触发路径可用，不是模型质量基准。
- 模型调用延迟约 10–20 s；验收每次请求 25 s 上限、最多两次尝试，准备总预算 60 s。
- `communication` 目前是规则与 run 的声明事实；T29 自身不产生通知或投递，监督视图读取它（T24/T18）后再决定呈现方式。
- 资源预算覆盖 run 次数、准备超时与产物字节；不声明 CPU/内存配额。
- 定时组合使用真实时钟调用 `tick()`，但未启动真实计时循环；T28 已单独验收真实 runner。
- 没有 host/CLI/UI 入口；规则、运行历史与产物只通过公开 Engine 查询（T49 负责编辑界面）。
- T29 仍 open，等待合入 `dev` 与发布。
