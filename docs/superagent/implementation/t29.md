# T29：在规则预算内主动准备可审阅结果（核心）

- Issue：[T29 / #57](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/57)。
- 固定实施基线：`3e807ea`。

## 已交付

- 版本化 `ProactiveRule`：触发 actor 种类、addressing、文本模式、沟通方式、每窗口预算与启用状态；revision CAS、重放与非法正则/未知键拒绝。
- observe 只记录 `proactive-run`，不调用准备回调、不启动 Worker。
- auto 只处理命中规则的候选；非人类/ambient 噪声记录 `suppressed`，连续回声不消耗准备预算；超出窗口预算记录 `budget-exhausted`。
- 准备使用 root 下的隔离目录与剩余预算；准备回调通过注入契约执行，返回有效摘要记录 `prepared`，无有效结果记录 `silent`，异常/超时记录 `failed`。
- 准备不产生 Outbox、发布、发信、PR 或合并权限；暂停全局处理时不评估主动规则。
- 状态在事务中先预留，准备在事务外执行，完成后按同一运行身份结算；同一事件同一规则重放不重复运行。
