# T28：用定时来源产生可追溯且不重复的候选（核心）

- Issue：[T28 / #56](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/56)。
- 固定实施基线：`a13db2e`。

## 已交付

- `ScheduleSource` 具有独立 `ruleId`、时区、间隔、稳定 occurrence ID 和持久 `schedule-state`。
- 首次 tick 产生当前 occurrence；同一 tick 重放不重复；漏执行按 `skip`/`once`/`all` 策略和 `maxCatchUp` 上限补发。
- 每个 occurrence 经统一 `receiveSource`/Gate 进入普通候选流程，不把计时器当作无限授权。
- 暂停期间仍记录 occurrence 事实，恢复后继续；时区非法和超限配置拒绝。
- `ScheduleRunner` 启动时立即 tick，并按声明间隔运行；`stop()` 清理定时器。
