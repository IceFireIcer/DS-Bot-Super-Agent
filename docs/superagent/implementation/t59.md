# T59：新增 ds-superagent profile 并接通现有聊天界面

- 票：[T59](../issues/T59.md)（本地票，尚未发布到 GitHub）。
- 规格：v2.1 D01、D09、D17、D18、D20。
- 实现提交：`a7cc225`（profile 与接线）、`c0465da`（resume、fail-closed 与锁文件修正）。
- 日期：2026-11-12。

## 已交付

- `superagent/src/profile.ts` 新增 `ds-superagent/profile` Cordis 插件：
  - 从 `DSH_HOME` 派生 `<DSH_HOME>/core/state.sqlite`；
  - 创建 production Engine factory，发布 `botExecutionAdapter`；
  - 缺失 `DSH_HOME` 时以 `INVALID_CONFIG` 失败；
  - 通过 `mountBotExecutionAdapter` 与 `ds-bot-host` 共用关闭生命周期。
- `superagent/package.json` 新增 `./profile` 导出和 `dsh.bundle.patch`；`superagent/cordis.patch.yml` 插入 `superagent-profile` 行。
- `DsBotExecutionAdapter` 新增 `resume`，并加入 `supports()` 允许的操作；stop 后可用原 Ticket 显式恢复。
- `app/src/profile.mjs` 新增 `SUPERAGENT_PROFILE`、`SUPERAGENT_BUNDLES`、`activeProfile()`、`profileHome()` 和参数化的 `loadAppProfile(profile)`。未知的非空 `DS_BOT_PROFILE` 明确失败，不再静默启动旧团队。
- `app/src/main.mjs` 选择 profile 后把 Super-agent 数据放在 `<dataDir>/superagent`，使用独立 Host 锁、`DSH_HOME` 和工作区；该 profile 不导入旧团队。
- `app/src/host.mjs` 通过 `runProfile` 启动所选 profile；`app/src/superagent-patch.mjs` 通过 `patchFiles` 设置 `executionAdapterRequired: true`，缺少 adapter 时不会回退旧核心。
- `app/package.json` / `app/package-lock.json` 增加 `ds-superagent` file 依赖。
- 新增 `app/scripts/check-superagent-profile.mjs`，用真实 `runProfile` 启动新 profile 并检查 adapter、web server、connection、Session 服务。
