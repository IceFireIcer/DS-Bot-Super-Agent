## 已交付

- `superagent/dev/real-model-adapter.mjs`：公开 DSH `LlmAdapter` 的 OpenAI-compatible 实现。它把 DSH 消息、工具声明和工具结果投影到 provider，把文本、推理、tool call 和 usage 投影回公开 chunk 词汇；每次请求受 request/token/timeout 预算约束，错误不包含凭据。
- `superagent/dev/t57-env-check.mjs`：不打印凭据的环境检查。模型检查做一次真实最小请求；GitHub 检查读取仓库与当前 actor，并要求 `push`/`maintain`/`admin` 之一；飞书检查用 `FeishuOpenApi.setup` 验证 tenant 与每个 chat。缺少飞书配置时明确返回 `unverified`，不伪造通过。
- `superagent/dev/t57-model-acceptance.mjs`：真实模型样本，覆盖跨信道意图、范围遵守/注入抵抗、Supervisor 语义评估和受信配置指令；记录 provider/model、请求数、token、耗时、工具调用和结果。
- `superagent/dev/github-acceptance.mjs`：新增 `SUPERAGENT_ACCEPTANCE_MODEL=real` 路径，真实模型驱动 Router/Worker 完成 GitHub 输入与 PR 完成条件；原 T27 场景继续使用真实 GitHub delivery channel 和原生回执。真实模型轮次使用 55 s Session 预算与 60 s Effect 预算。
- `superagent/package.json` 增加 `acceptance:t57:env`、`acceptance:t57:model`、`acceptance:t57:proactive`、`acceptance:t57:github`。

## 飞书

本轮没有真实飞书租户、群或权限配置，因此没有运行讨论接收、原地回答和结果交付。环境检查把飞书明确标为 `unverified`；T57 不能据此关闭。补验需要：

- `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_TENANT_KEY`；
- 一个隔离测试群 `FEISHU_CHAT_IDS`，以及机器人可读历史和回复的权限；
- 群内一条发给机器人的真实消息，用于验证接收、`ask_human`/授权回答和原生 reply receipt。

## 边界

- 真实模型样本只覆盖一个 provider/model 和小样本；不是模型质量基准。
- Supervisor 的冲突输入是受控语义探测，不是真实 Ticket 状态迁移；T48 的 Engine 集成证据仍然有效。
- 没有托管 Host、第二设备或真实飞书；这些分别由 T58 和本票飞书补验承担。
- 不在仓库、日志或输出中保存凭据；脚本只从环境读取并只输出 endpoint host、模型 ID、计数和脱敏身份。
