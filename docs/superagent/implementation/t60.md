# T60：复制聊天界面为 ds-superagent-ui（进行中）

- 票：[T60](../issues/T60.md)（本地票，尚未发布到 GitHub）。
- 状态：**部分实现，未达 T60 验收**。已复制聊天源码并让独立 profile 启动、发送和读取 Engine 结果；窄接口、隐藏未实现入口和主聊天投影仍未完成。
- 日期：2026-11-12。

## 本次实现

- 新增 `superagent/ui`：从 `ds-bot/src/client/` 与 `ds-bot/src/shared/` 复制源码，生成 `client.js`，bundle id 为 `ds-superagent-ui`。未手工编辑生成文件。
- 新增 `superagent/host`：挂载现有 DS Bot Host 服务端协议，不加载 DS Bot 客户端；要求 `executionAdapterRequired: true`，没有 Super-agent adapter 时 fail-closed。
- `ds-superagent` profile 的 bundles 改为 `dsh-base`、`dsh-web-app`、`ds-superagent`、`ds-superagent-host`、`ds-superagent-ui`。profile 层不再直接挂载 `ds-bot` bundle。
- `superagent/src/ds-bot-adapter.ts`：
  - 支持在 Bot 首次 Session 尚未进入 roster 时，用 DSH `sessionController` 的真实 Agent 完成标题和工具初始化；
  - 暴露绑定 Ticket 的 `conversation` 查询；
  - 当原生 Worker 日志没有可显示行时，`chatPage` 回退为绑定 Ticket 的请求与结果，避免活动聊天显示为空。

## 未完成（不能声称 T60 通过）

- 复制 UI 仍调用 `/api/bot`，没有 `/api/superagent` 窄路由；`superagent/host` 仍挂载旧 DS Bot Host 服务端。
- 复制 UI 仍包含团队、群聊、浏览器、附件、steer、记忆、日程、用量和密钥入口；尚未隐藏或明确拒绝。
- 复制 UI 的主聊天由 DSH Session projection 驱动。Engine 的 Worker 在独立 Session，当前没有把结果投影到主聊天；`chat` 回退只保证读取接口有请求和结果，不等于主聊天已显示。
- Attention 回答、stop、resume 的复制 UI 入口、重连补读和证据展开尚未实现。
- `/api/bot` 的完整端点仍在服务端存在，不符合 T60 的“只交付 v1 窄接口”。
- 真实模型、真实信道、托管 Host 和第二设备仍由 T57/T58 验收。
