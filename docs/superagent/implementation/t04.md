- Issue：[T04 / #32](https://github.com/IceFireIcer/DS-Bot-SuperAgent/issues/32)。依据：规格 v2.1 D02/D03/D04/D17，A01/A18，用户故事 32/33/73。
- 固定实施基线：`9f41b61`；实现提交：`aa2c645`、`c31aad2`；收尾兼容修复在当前交付提交中。
- 实现使用公开 `Engine`、`Storage` 和 CLI 边界；来源适配器把来源实例、Actor、Thread、原生版本、事件类型和删除证据作为受信输入。没有接入真实 GitHub/飞书账号，也没有读取用户 DSH 数据。

## 行为

`receiveSource` 将来源对象键固定为 Instance、desktop source instance、Thread 和 native object ID，事件事实另存为不可变 `source-event`，当前内容另存为 `source-object`。传输 command ID 具有独立回执和 fingerprint；重复输入复用回执，内容改变返回 `IDENTITY_CONFLICT`。接收 Actor、Thread scope 和版本排序契约来自 Engine 配置，正文不能覆盖它们。

序列版本只允许规范无符号整数。较旧编辑不覆盖当前投影；同版本异文进入 `conflict`，不可比版本进入 `unknown`，两种状态都不能成为新任务候选。删除必须有有界 native deletion evidence，形成永久 `deleted` tombstone；迟到编辑不复活对象，删除也不撤销已经建立的 Mandate。

`acceptSource` 在同一事务中核对当前 event ID，只接受当前且有正文的投影，并把原始 source event、Thread 和 native version 写入 Trigger/Delivery。旧 Ticket 的 Mandate 保留原始内容。结果回执继续沿原 source event 的 Thread 交付。legacy `submit` 与 versioned intake 通过持久 `source-mode` 事实互斥；这防止删除后绕过 source projection，也防止从旧 direct 数据切换到 versioned source。

## 验证

```sh
cd superagent
npm run typecheck
npm test
npm run lint
node dev/source-load.mjs
```

当前核心全量 **62/62**，在 Windows Node 22.19.0、Node 24.22.2 和 Node 25.4.0 均通过；typecheck 和 lint 通过。测试覆盖：接收 scope 和伪造字段拒绝、同号来源实例/Instance 隔离、乱序编辑、同版本冲突、opaque unknown、tombstone、候选拒绝、旧 Mandate 保留、历史分页、事务回滚、未知提交对账、CLI 接收/查询/历史/接单、native Router/Worker Thread 交付，以及 pre-T04 direct 数据没有 `source-mode` 时跨 object ID 的兼容检测。

`node dev/source-load.mjs` 在隔离临时 SQLite 中接收 150 个版本、并发重试 20 次并分页读取 3 页历史；所有重试复用同一 event，150 条历史完整可读，当前版本为 150。一次 Windows Node 25.4.0 运行的接收耗时为 p50 0.854 ms、p95 1.317 ms、max 14.968 ms；queue limit 128、lock wait 250 ms 是已有 SQLite adapter 的边界，不是生产 SLA。

Node 24.0.0 的单独公开 DSH subprocess probe 失败于 `dsh-subprocess-local` 的 Windows Job runner 在退出码 0 后未确认 managed range empty；同一 probe 在 Node 24.22.2 和 25.4.0 通过。该问题位于 provider/runtime 组合，不能通过修改 DSH 安装规避；CI 的 Node 24 浮动版本和本地 24.22.2 已通过。

两轴审查的 Standards 和 Spec 均为 0 个剩余问题。T04 只交付受信 source intake 和本地持久模型；真实平台身份/版本验证、跨信道订阅与关联、批量 Eval、GitHub/飞书 adapter 属于后继票。来源版本的协议替身不代表真实外部信道验收。
