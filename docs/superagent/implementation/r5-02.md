# R5-02：从 Main 委托一项本地工作并收到有界结果

- 工单：[R5-02 / #94](https://github.com/IceFireIcer/DS-SuperAgent/issues/94)。
- 规格：[R5 总规格 / #1](https://github.com/IceFireIcer/DS-SuperAgent/issues/1)。
- 前置：[R5-01 / #93](r5-01.md)。
- 日期：2026-11-14；实现位于 `dev`，未发布。

## 交付行为

Main 的 `delegate_work` 工具要求一个明确目标、约束和可观察验收标准。Engine 持久化版本化 WorkBrief、原始 Main 消息依据、授权 Actor、Instance、Main/Router Session、配置 revision、工作区和同事务 notice intent。稳定 command ID 按输入指纹去重；异文复用拒绝。没有受信本地 workspace 时工具明确拒绝，不建立 Ticket。

Router 通过独立公开 DSH loop 收到 WorkBrief，只能调用 `establish_local_work` 建立一项工作。该命令使用稳定 Ticket command ID，经 Engine 创建唯一 Trigger、Mandate 和 Ticket；随后既有 Router/Execution 流程固定 Assignment，并在产品配置的 LocalEnvironment 内启动真实 Worker。Worker 只能使用该 workspace 暴露的 read/write 工具，不获得 Shell 命令权限。

Worker 只有在写入后读回验收内容并成功调用 `report_ready` 时，才生成成功 Outcome。Ticket、Mandate、Assignment、ReadyReport、Outbox delivery、WorkBrief、WorkReceipt 与 WorkOutcome 是独立持久事实；Outbox pending 不能表示 Worker 已完成。读到有界 work card 时按持久 Ticket/Report 投影出当前状态和最多十项 artifact 引用，不把 Worker transcript、工具日志或 Shell 输出交给 Main。读历史时补写相同 report 对应的 Outcome，刷新和重启保持稳定身份。

主对话历史查询携带最近 20 项授权工作卡：WorkBrief ID、Ticket ID、约束、验收条件、接单回执、状态、结果、验证摘要与 artifact 路径/哈希。Main 还能以 WorkBrief ID 调用 `query_work`。失败或无 ready report 的 Worker 显示为失败、阻塞或未知；Main 回复成功本身不改变工作状态。

## 验证

- Engine/SQLite 端到端回归：真实 Main → Router → Ticket/Mandate/Assignment → LocalEnvironment Worker；文件写入、读回、ready report、artifact 与工作卡均核实。同一个 Main 命令重试不重复派工，异文复用被拒绝。
- 负例回归：Worker 结束但没有 ready report 时工作卡明确失败，主对话仍为正常完成状态；未连接 workspace 时委托保持不可用且不建 Ticket。
- PostgreSQL 公开 Engine 合约：本地工作流及 Main 重启后 WorkBrief、receipt、Ticket 和 report ID 持久且不重复；全量 superagent 套件中的 PostgreSQL 检查通过。
- 真实 `ds-superagent` DSH profile：mock 三层 route，实际 Main 工具回合、本地文件写入/读取/报告及公开产品历史检查通过；原生 Session unary/stream 写入口仍被拒绝。
- 真实 Edge headless + DSH Web：6 项界面检查通过，显示 WorkBrief/Ticket 身份、验证结果和证据；刷新后卡片保留，390px 深色/减少动态效果无横向溢出或未捕获页面异常。截图在忽略目录 `temp/r5-02/main-work.png` 与 `main-work-mobile.png`。
- 最终全量验证：superagent 551/553 通过、2 项按平台跳过、0 失败；DS Bot 1442/1444 通过、2 项按平台跳过、0 失败。Main/委托与 PostgreSQL 定向测试、profile 子进程、客户端生成检查、样式/i18n、lint、类型检查、UI boundary、实现记录链接和泄漏扫描均通过。真实 DSH Web + Edge 检查 6 项通过，包含工作结果、刷新、跨 Instance 拒绝、原生 Session 写拒绝和 390px 深色布局。

## 边界

本票仅支持一份明确授权、单项本地工作；Main/Router 不做复合分解。远程执行、目录选择器、后台任务重启恢复、自然语言跟进、工作控制及多项并行由后续 R5 票完成。没有真实模型或外部信道的验收不在本票证据内。
