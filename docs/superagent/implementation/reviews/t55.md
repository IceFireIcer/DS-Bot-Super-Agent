## Standards

- **发现并修复 P2：** 连续场景的 teardown 遇到一个 disposal 失败会跳过后续环境、Session、存储及目录清理，违反“停止本轮所有服务和进程”。修复为按归属顺序尝试全部 disposer、最后汇总错误，目录清理在 finally 中执行。修正后真实进程/Session 场景单文件通过。
- **复审发现并修复 P2：** 新 CLI 测试夹具也有类似问题：一个回调或 PID 检查异常会跳过余下清理。改为独立尝试 runner、各子 PID、关闭等待及目录删除，再汇总错误。此项是测试夹具清理，不改变 runner/产品行为。
- **完成检查：** runner 必需的 `t55-evidence.md` 随本轮交付，不能只留在未跟踪工作区；独立旧插件/app 报告、远端报告与初次/最终运行 JSON 均纳入提交。
- 未发现需为本票修复的 baseline smell；验收脚本不进入生产入口，没有新增 DSH 私有依赖、用户数据路径或产品功能。

## Spec

- **发现并修复 P2：** preflight 文件缺失前未写新报告，可能留下上次成功报告。每次建立 UUID 轮次和 preflight 快照，再检查前置；异常更新本轮 failed 和最新快照，保留旧轮次。公开 CLI 回归验证这一失败窗口。
- **TDD 证据：** 在独立夹具复制修正前的暂存 runner，preflight 回归实际得到 0 pass / 1 fail（旧报告仍为 passed，期望 failed），然后修正版通过。没有替换工作区 runner；不是仅添加一个从未见红的成功测试。
- **发现并修复 P2：** runner 的中断处理未清理活动测试树。增加 SIGINT/SIGTERM 处理，终止归属本轮的进程树、等待 Windows taskkill 完成并记录 aborted。POSIX 实际信号和 Windows 信号差异单独验收；没有把 Windows skip 当通过。
- **产品边界：** 桌面新核心绑定、真实同 Ticket A→B/外发、托管/OS 生命周期、语义模型、T54 不等负载等仍阻止 A26 和四目标完整验收。T55 逐项写未验收并归回原行为票，符合“只汇合验证”的范围，不能将这些作为已解决项。
- 连续场景核验真实命令 stdout/exit、附件、人工 stop、重开后的历史及显式 resume；GitHub 部分明确仅验证授权改投元数据，未宣称真实外发。没有发现产品功能范围扩张。
