# T39 双轴审查

- 审查基线：`4fb2106`。
- 审查方式：两个独立只读子代理分别按 Standards 与 Spec 审查暂存 diff；主代理核对并修复。
- 范围：Git worktree 预检、manifest、目标核验、设备 `workcopy.inspect`、测试与验收脚本。

## Standards

- 采纳：移除描述性 JSDoc，改为说明有界快照的理由；抽出 `inspectEnvironmentWorkCopy` 和 `uniqueBlockers`，消除 prepare/verify 的重复检查；统一使用 `WorkCopyBlocker`、`WorkCopyDigest` 和 `WorkCopyFileState` 集合，减少原始字符串/匿名形状。
- 采纳：`WorkCopyComparison.filesToCopy/totalBytes` 重新用于准备记录，不再是未读字段。
- 保留：`work-copy.ts` 仍同时包含 Git runner/porcelain 解析/哈希/比较；当前是单一领域模块，拆成多个小文件会增加跨模块传参，暂不拆。
- 保留：测试中两次打开 LocalEnvironment 的装配代码仍重复；测试场景差异较大，抽 helper 会把失败定位绑在同一夹具上。

## Spec

- 采纳：目标中未列入清单的 `deleted` 文件也触发 `unknown-target-change`，不再被跳过。
- 采纳：prepare/verify 记录并复核 Environment kind/root、deviceId/incarnation、version/fingerprint；环境身份变化成为 `source-environment-changed`/`target-environment-changed`。
- 采纳：probe 异常不再在 blocker catch 之前抛出；offline/目录变化等会持久化为 `handoff-blocked` 记录。
- 采纳：`WorkCopyFile.executable` 进入清单和比较，覆盖 Linux 可执行位；Linux 第二设备验收实际通过。
- 保留：preflight target 是显式目标，只受 Environment/actor 授权约束；Ticket/Mandate 目标重验和旧 Assignment 结束属于 T40。
- 保留：实际文件传输仍由显式同步/T40 执行；T39 只生成并核验清单，不把缺同步证据误报为 unknown。
