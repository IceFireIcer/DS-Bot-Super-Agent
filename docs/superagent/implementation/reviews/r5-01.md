# R5-01 双轴审查

- 日期：2026-11-14。
- 规格：[#93](https://github.com/IceFireIcer/DS-SuperAgent/issues/93)、[R5 总规格](https://github.com/IceFireIcer/DS-SuperAgent/issues/1)。
- 基线：`4e666ee44c1ac31bad7c8e4d66fb0601fd1afbd5`，并保存开始时未提交文件快照；只审查本票增量。
- Standards 与 Spec 由两个独立代理并行审查，未扩大到既有未提交改动。

## Standards

初审 2 项：Main 未记录配置版本、输入框高度低于 80px。已添加 Main role-config-use 和对应 Engine 行为断言，输入框最小高度改为 80px。复审发现配置记录后仍可被并发保存改变；现将 route、instructions、skills 的不可变快照传入 NativeSessions，真实异步间隙测试通过。

## Spec

初审 1 项：原生回合完成与业务回复投影之间中断会把已完成回复永久标为失败。已通过原消息身份和当前活动命令对账原生回合，刷新幂等补写回复；故障注入测试证明不重复模型请求。复审进一步覆盖先到下一条消息、再刷新，以及失败命令按原身份重试，确认不会覆盖待对账指针。

复审另发现原生 Session 的路径规范化与 WebSocket 旁路。现以公开 Cordis service isolation 移除产品 Gateway 对原生 Session 控制器的访问，HTTP hook 先规范化路径；真实 HTTP 原始路径和真实 WebSocket 检查均被拒绝，公开 Gateway unary/stream 合约也被拒绝。

最终精确提交树复审：Standards 0 项，Spec 0 项，无剩余具体阻塞。工作委托、Main 故障期间的自动排队恢复、Router/Worker 观察、停止工作等仍按 R5 后续票实施。
