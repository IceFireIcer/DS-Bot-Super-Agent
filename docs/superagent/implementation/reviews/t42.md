# T42 双轴审查

- 基线：`2aecada`；两个独立只读子代理分别完成 Standards 与 Spec 初审、复审，主代理修复并验证。

## Standards

- **修复：** `PostgresTransaction` 在 callback 结束或异常后立即失效，防止 retained tx 使用已释放的 PoolClient。
- **修复：** Engine README 示例加入必需的 `allowedActorIds`；新增依赖改成精确版本。
- **修复：** 删除未用的 `commitProxy` once 参数，legacy schema 探测函数改名；SQLite/PostgreSQL 共享记录和查询容量常量。
- **保留判断：** SQL 层按少量业务操作写显式语句符合现有风格；对协调行、记录表各自校验列和主键是不同契约，抽象成生成式通用 schema checker 反而难读。

## Spec

- **修复：** AC1/D13，tx capability 失效；公开 Engine 对同 command ID 异文返回 `IDENTITY_CONFLICT`；公开 Effects 验证四种旧结果不能覆盖新 generation。
- **修复：** AC2/AC4，协调行和初始化受连接级 timeout，锁失败仍映射 55P03；增加真实 PostgreSQL 40P01 到 `commandTransaction` 整事务重试、statement timeout、三次 40001 耗尽、COMMIT 时明确 40001/23505 分类及容量负载证据。
- **修复：** AC5，版本表在事务 advisory lock 下核验列、类型、nullable、identity、PK；旧表独占锁后生成 fsync 并逐字节校验的备份，测试四个 DDL 窗口中断、迁移 COMMIT 前/后断连，移植备份到独立库并查询恢复事实。
- **修复：** 移除公开 `SERIALIZABLE` 测试配置和额外 command 导出；READ COMMITTED 下的触发器 40001 注入只证明服务器错误分类与整事务重跑，不声称产生了原生 SSI 冲突。
- **修复：** open/reconnect 的 pool.connect 错误统一映射；旧表结构复核在 ACCESS EXCLUSIVE 锁内；连接串 options 不能绕过首次协调行插入的锁/语句预算；池等待 timeout 归 `STORAGE_UNAVAILABLE`。
