# T30：接收飞书讨论并保持来源归属（适配器核心）

- Issue：[T30 / #58](https://github.com/IceFireIcer/DS-Bot-Super-Agent/issues/58)。
- 固定实施基线：`a13db2e`。

## 已交付

- `FeishuSource` 校验 tenant、chat、sender 与原生 message ID；按 `(tenant, chat, message)` 映射 Thread/object，保存原生版本和删除证据。
- 来源自身消息过滤但推进游标；其他事件仅在记录成功后推进 `channel-cursor`；乱序/重放不重复接单。
- 两个 tenant 或 chat 的相同 sender/number 不共享作用域；跨 chat 事件拒绝。
- `FeishuPoller` 在 setup 成功后轮询；来源故障有独立健康/错误与游标，`stop()` abort 并等待当前轮询结束。
